# 🥊 Арена переговоров: Spark AI

Интерактивный тренажёр сложных деловых переговоров с адаптивным ИИ-оппонентом **Spark** (Хакатон «Лидеры цифровой трансформации 2026»).

---

## 🌟 Основные возможности

1. **3 уникальные персоны оппонента:**
   * **Жёсткий (The Shark):** давит авторитетом, ставит ультиматумы, апеллирует к конкурентам и рынку.
   * **Кооперативный (The Partner):** техника «Да, и...», открытые вопросы, поиск Win-Win решений.
   * **Манипулятивный (The Trickster):** искажает факты, сеет сомнения, маскирует урезание SLA.

2. **Динамическая игровая механика и шкалы состояния:**
   * **Доверие (Trust):** от -100 до +100.
   * **Напряжение (Tension):** от -100 до +100. При превышении порога `> 50` активируется экранный виньетинг опасности и пульсация интерфейса. При `> 85` оппонент срывает переговоры.
   * **Готовность к сделке (Deal Progress):** от 0 до 100%.

3. **Ветвление и 3 типа концовок:**
   * **Сделка (Deal)** — победа сотрудничества или сильной BATNA.
   * **Компромисс (Compromise)** — взаимные уступки.
   * **Провал (No Deal)** — срыв переговоров из-за эскалации конфликта.

4. **Глубокий разбор (Debrief):**
   * Анализ по **Гарвардскому методу принципиальных переговоров** (люди vs проблемы, интересы vs позиции).
   * Оценка применения **вопросов SPIN** (Situation, Problem, Implication, Need-Payoff).
   * Оценка работы с альтернативой **BATNA**.
   * Список сильных сторон, допущенных ошибок и персональные рекомендации.

5. **Работает как с Gemini API, так и в автономном демо-режиме.**

## 🚀 Быстрый запуск

### Вариант 1 (В один клик на Windows):
Дважды кликните по файлу **`run.bat`** (или запустите `run.ps1` в PowerShell).

### Вариант 2 (Через терминал):
```bash
# Перейдите в папку проекта
cd C:\Users\tre\.gemini\antigravity\scratch\negotiation_arena

# Установите зависимости
python -m pip install -r requirements.txt

# Запустите сервер
python -m uvicorn backend.main:app --reload --port 8000
```

После запуска откройте в браузере: **`http://localhost:8000`**

## 🔑 Настройка Gemini API

Вы можете задать ключ двумя способами:
1. В интерфейсе приложения нажать иконку шестерёнки ⚙️ в правом верхнем углу и ввести ключ.
2. Либо создать файл `.env` в корне проекта:
   ```env
   GEMINI_API_KEY=ваш_ключ_здесь
   ```
*(Если ключ не задан, приложение продолжит работать в автономном эвристическом демо-режиме)*.
